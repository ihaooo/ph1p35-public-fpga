# 验证说明

## 1. 验证边界

公开包验证的是可独立发布的 RTL 模块，不声称完整系统可以在当前公开源码上复现。完整原型中的 MCU、模型和污渍检测核心不在本仓库。

## 2. 仿真验收

运行：

```powershell
cd sim\modelsim
.\run_all.ps1
```

验收标准：

- 所有源文件编译通过；
- 每个测试打印 `PASS`；
- 没有 `$fatal`、未初始化状态或 `X/Z` 断言；
- 进程返回码为 `0`。

本次公开包的实际验证记录：

- ModelSim 10.6d：`vlog -sv` 编译全部公开 RTL 和测试平台通过；
- 本机 ModelSim 许可证不可用，`vsim` 未能启动；
- Icarus Verilog 12 项测试全部打印 `PASS`。

## 3. TD 验收

TF/SPI 独立工程：

- 器件为 `PH1P35MDG324`；
- 顶层为 `tf_probe_top`；
- Synthesis 无 error；
- Place & Route 完成；
- WNS 不小于 0；
- 新生成的 `.bit` 成功通过 SRAM 下载。

## 4. 实板验收

- 50 MHz 输入和复位正常；
- TF 卡断电插入后上电；
- 心跳指示正常；
- CMD0 成功或失败指示与串口/逻辑分析仪结果一致；
- 连续运行期间不复位、不锁死；
- 切换其他位流前保留可恢复版本。

## 5. 不作出的声明

当前公开仓库不作以下声明：

- 公开源码可以生成完整比赛位流；
- 小样本离线准确率等于现场准确率；
- TF CMD0 通过等于 FAT32 和模型读取通过；
- MCU 固件已经在所有板卡版本上验证；
- 公开模块未经修改即可在任意板卡上满足时序。

赛后发布核心代码时，将补充标准测试集、综合资源、时序、FPS、推理延迟和长期运行结果。
