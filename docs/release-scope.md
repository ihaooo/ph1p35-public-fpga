# 开源范围与赛后计划

## 1. 公开原则

比赛期间只公开：

- 可以独立理解和复用的 FPGA 基础模块；
- 不含核心检测策略的板级 I/O；
- TF/SPI 物理探测；
- ModelSim 自检测试；
- 不暴露私有接口的架构和构建说明。

这样既能展示工程能力和可复用成果，也能保护比赛期间的核心实现。

## 2. 当前公开

| 模块 | 公开状态 |
|---|---|
| 视频流接口 | 公开 |
| AE、AWB、直方图、像素处理 | 公开 |
| 状态叠加和显示亮度 | 公开 |
| 按键、拨码、数码管、蜂鸣器、舵机 | 公开 |
| 帧编号、CDC 快照、看门狗 | 公开 |
| TF/SPI 独立探测 | 公开 |
| ModelSim 脚本和测试平台 | 公开 |

## 3. 暂不公开

以下内容已经完成原型设计或验证，但当前不发布源码：

- PH1P35 RISC-V MCU 启动、BSP、应用固件；
- TF FAT32 模型读取和 CRC 校验；
- INT8 分类器运行时；
- 污渍检测、连通域、目标定位、形态分类和风险决策；
- 模型权重、训练脚本、数据集和验证样本；
- 完整系统顶层、私有 APB 连接、完整 TD 工程和 `.bit`。

这些文件不出现在当前公开目录中，用户也不应通过其他历史公开位置继续传播核心源码。

## 4. “已实现”的含义

本项目对核心功能使用“已实现”描述，含义是：

- 已在比赛原型中完成设计和联调；
- 已获得阶段性板上或离线结果；
- 当前公开包不包含其实现源码。

“已实现”不表示当前公开代码可以直接构建完整系统，也不表示实验结果已经达到量产标准。

## 5. 赛后开源顺序

1. 清理私有仓库历史并检查第三方许可；
2. 发布模块接口和完整顶层；
3. 发布污渍检测 RTL 和自检测试；
4. 发布 MCU 固件、TF 模型读取和 APB 接口；
5. 发布训练、量化、模型格式和数据说明；
6. 发布标准化测试结果；
7. 根据比赛或学校要求补充硬件、报告和使用文档。

## 6. 发布前检查

- 删除个人路径、邮箱、令牌和板卡序列号；
- 确认数据集、模型和第三方 IP 的许可证；
- 检查压缩包和 Git 历史，而不只是检查最新快照；
- 对完整位流和模型文件计算校验和；
- 在不同干净目录重新编译和运行 ModelSim；
- 确认 `.gitignore` 不包含需要提交的源文件。
