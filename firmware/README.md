# MCU 固件状态

PH1P35 RISC-V MCU 固件已经在比赛原型中实现，包括启动环境适配、TF 卡模型读取、模型校验和应用联调的基础流程。

本目录当前不包含固件源码。原因是 MCU 启动地址、APB 映射、模型读取和分类输出直接关联比赛核心实现。

比赛结束后将发布：

- FutureDynasty 工程创建步骤；
- 启动、链接和 UART 配置；
- APB 外设地址约定；
- TF FAT32 模型读取；
- 模型 CRC 校验；
- MCU 与 FPGA 的数据交换协议；
- 可编译的应用工程。

当前公开模块中的 `rtl/tf_card/` 只提供 SPI/APB 硬件端，不包含 MCU 软件。
